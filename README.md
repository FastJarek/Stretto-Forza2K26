# Stretto-Forza2K26

## Drift Masters 2K26

Gra wyścigowo-driftingowa 3D w stylu Assetto Corsa na Androida i do przeglądarki.

### Pobierz APK

**[DriftMasters2K26-v1.0.apk](https://github.com/FastJarek/Stretto-Forza2K26/releases/download/v1.0/DriftMasters2K26-v1.0.apk)** · [Wydanie v1.0](https://github.com/FastJarek/Stretto-Forza2K26/releases/tag/v1.0)

Android 7.0 (API 24)+. Po pobraniu zezwól na instalację z nieznanych źródeł.

### Zawartość

- Treningi: Skipad, Bihoku, Pętla Startowa, Slalom Miejski.
- Wyścigi: Tor Poznań i Suzuka — bramki, okrążenia, medale.
- Drift / free roam: Strefa Przemysłowa, Górska Przełęcz, Port Nocą — bez bramek i limitu czasu.
- Auta: Toyota AE86, BMW E36, Nissan S13 (drift) oraz BMW E60, Mazda Miata, Gokart (wyścigi).
- Fizyka jazdy z poślizgiem, drift Meyer (kąt, czas, punkty, combo).
- Setup auta: silnik, kąt skrętu, przełożenie, przyczepność, rozkład hamowania, zawieszenie, dyferencjał, skrzynia.
- Sterowanie: dotyk, żyroskop lub klawiatura + mysz; mysz działa w menu i ustawieniach.
- Klawiatura: `W` gaz, `S` hamulec, `A`/`D` kierownica, `Spacja` ręczny, `Q`/`E` biegi, `C` sprzęgło, `Tab` kamera, `Esc` menu, `R` reset.

Szczegóły, sterowanie i instrukcja zbudowania: [`drift-masters-2k26/README.md`](drift-masters-2k26/README.md).
